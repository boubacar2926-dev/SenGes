# 🛒 SenGes — Simplifiez la Gestion de votre PME

🔗 **[Voir la démo en ligne](LIEN_A_AJOUTER)**

SenGes est une application web de gestion pour petites et moyennes entreprises (PME). Elle permet de suivre ses produits, ses transactions de vente et ses performances commerciales depuis un tableau de bord clair et en temps réel.

Projet développé en Laravel dans le cadre de ma montée en compétence en développement full-stack, avec une approche produit : landing page marketing, authentification, dashboard fonctionnel et statistiques.

---

## ✨ Fonctionnalités

- **Landing page** de présentation avec mise en avant des bénéfices (gestion produits, transactions, statistiques temps réel)
- **Authentification** (connexion / inscription)
- **Gestion des produits** : ajout, modification, suivi de stock
- **Gestion des transactions** : enregistrement et suivi des ventes en un clic
- **Tableau de bord** avec revenus des 7 derniers jours (graphique)
- **Statistiques de ventes** : total des ventes, nombre de transactions, produits les plus vendus
- **Interface responsive**, utilisable sur mobile et desktop

## 🚀 Installation locale

```bash
git clone https://github.com/boubacar2926-dev/SenGes.git
cd SenGes
composer install
npm install && npm run build
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```
