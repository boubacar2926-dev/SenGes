# 🚀 SenGes - Plateforme de Gestion

> **SenGes** est une application web moderne développée avec Laravel et Tailwind CSS, déployée sur Render avec une base de données PostgreSQL.

🌐 **Démo en ligne :** [https://senges.onrender.com](https://senges.onrender.com)

---

## 🛠️ Technologies utilisées

* **Backend :** PHP 8.2 / Laravel
* **Frontend :** Blade, Tailwind CSS, Vite
* **Base de données :** PostgreSQL (Production) / MySQL (Local)
* **Déploiement & Conteneurisation :** Docker, Apache, Render

---

## ✨ Fonctionnalités clés

* 🔐 Authentification & Gestion des utilisateurs
* 📊 Tableau de bord interactif
* ⚡ Interface responsive avec Tailwind CSS
* 🗄️ Migrations et Seeders automatisés
